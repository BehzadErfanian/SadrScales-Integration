# SadrScales.Integration 1.1.1

> Release-candidate notes for SadrScales 5.5 compatibility certification. Do not publish as 5.5-certified until all certification gates pass.

## Purpose

This patch release keeps the existing public SQL Contract v1 and public SDK API unchanged while certifying that contract against the SadrScales 5.5 Release Candidate.

## Candidate baseline

- SDK candidate: `1.1.1-rc.1`
- Public contract: SQL Contract v1
- Target framework: `netstandard2.0`
- Existing certified baseline: Sadr Scales 5.2.1
- Target certification baseline: SadrScales 5.5 RC

## Source audit findings

The canonical `DLLs/Scripts/DB.sql` file is byte-identical from SadrScales `release/5.2` through `release/5.5`.

SadrScales 5.5 adds internal stable-identity support for PLUS by adding nullable `SADR_Scale.PlusDeviceId`, a filtered unique index for that identity, and allowing duplicate endpoint IP/port combinations. These changes are additive/internal for SQL Contract v1: the public SDK does not read `PlusDeviceId` and does not treat `ScaleIP + Port` uniqueness as a public identity contract.

No public API or Contract v1 expansion has been identified by the source audit, so the planned final version remains `1.1.1` if executable certification passes.

## Required evidence before publication

## Publication rule

Only after all gates pass:

- change package version from `1.1.1-rc.1` to `1.1.1`;
- add SadrScales 5.5 to the compatibility matrix;
- remove certification-pending wording;
- build the final release bundle and checksums;
- publish/tag the certified release.

No REST, Webhook, Command Mailbox, direct device protocol access or new public API is part of this patch release.
