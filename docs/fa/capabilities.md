# قابلیت‌های Vendor-Ready — Sadr Scales 5.2.1 / Integration 1.1.0

این صفحه نقشه‌ی سریع قابلیت‌های نسخه افزوده‌ی `1.1.0` است.

## کاتالوگ

- شعبه: خواندن / ثبت و ویرایش
- گروه کالا: خواندن / ثبت و ویرایش
- کالا / PLU: خواندن / ثبت و ویرایش / ثبت گروهی محدود / حذف منطقی
- تاریخچه قیمت: فقط خواندنی

راهنما: [کاتالوگ](catalog.md)

## ترازوها

- خواندن مشخصات ترازوهای ثبت‌شده
- وضعیت عمومی SQL: `Online / Offline / Unknown`
- درخواست ارسال مجدد خودکار کالا
- درخواست ارسال مجدد خودکار کلید سریع در مدل‌های پشتیبانی‌شده

راهنما: [ترازو، وضعیت و ارسال مجدد](scales-status-resend.md)

## پیکربندی ترازو

- تخصیص چندگروهی کالا به ترازو
- نگاشت اختصاصی PLU / ItemCode برای هر ترازو
- جایگاه اختیاری کلید سریع در نگاشت اختصاصی ترازو
- الگوی کلید سریع در سطح گروه
- عملیات Replace / Copy اتمیک و اعتبارسنجی‌شده

راهنما: [تخصیص، نگاشت و کلیدهای سریع](assignments-mapping-hotkeys.md)

## فروش و گزارش‌ها

- Feed افزایشی فروش با Cursor متعلق به نرم‌افزار مقصد
- Query فیلترشده و صفحه‌بندی‌شده
- Summary مشترک: تعداد ردیف، تعداد فاکتور، مبلغ، وزن و تعداد
- گزارش روزانه
- گزارش بر اساس ترازو
- گزارش بر اساس کالا

راهنما: [جست‌وجوی فروش و گزارش‌ها](sales-query-reports.md)

## فاکتور ساختاریافته

- دریافت با `TotalBarcode`
- دریافت با `ScaleID + FID`
- Header و Detail کامل
- ACK صریح و Idempotent فقط پس از Commit موفق نرم‌افزار مقصد
- فاکتور ACK شده همچنان کامل با وضعیت `AlreadyRead` برمی‌گردد

راهنما: [فاکتور ساختاریافته و ACK](structured-invoices.md)

## Demo و تست

- برنامه WinForms نمونه‌ی اجرایی
- داده Demo قابل تکرار با Seed مشخص
- محافظ Demo Database و Reset کنترل‌شده
- تست Vendor Acceptance فقط از روی Package

DemoLab جزو API تولیدی SDK نیست و برای دورزدن مرزهای رسمی SQL در محیط واقعی طراحی نشده است.

## مسیر Raw SQL

استفاده از C# الزامی نیست. نمونه‌های SQL متناظر برای زبان‌ها و پلتفرم‌های دیگر در [`samples/SQL`](../../samples/SQL/README.md) قرار دارند.

- Runtime Command دلخواه
- اجرای فوری Command و Progress واقعی دستگاه

Command Mailbox تایپ‌شده برای هر ترازو در برنامه Sadr Scales 5.3 در نظر گرفته شده است.
