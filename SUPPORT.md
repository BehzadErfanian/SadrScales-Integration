# Support

SadrScales-Integration is the official public integration toolkit for software vendors connecting POS, ERP and accounting systems to Sadr Scales.

## Public integration questions and reproducible bugs

Use GitHub Issues for public, sanitized integration questions and reproducible SDK/Contract v1 defects.

Before opening an issue:

1. confirm the Sadr Scales and SDK versions;
2. run Contract validation;
3. review `docs/en/troubleshooting.md` or `docs/fa/troubleshooting.md`;
4. reproduce with synthetic or sanitized data;
5. remove credentials, customer data and private implementation material.

## Security-sensitive reports

Do not use a public issue for vulnerabilities, credentials, private keys, customer data, unpublished device-protocol material or other sensitive information. Follow `SECURITY.md`.

## Commercial/deployment support

For customer-specific deployment, installation or commercial support, use Tozin Sadr's official support channels rather than posting customer details in this public repository.

Official website: https://sadrgroup.ir/

## Scope

This repository supports the public SQL Contract v1 and public Integration SDK. Direct PLUS/LSG/Aclas wire protocols, private Sadr Scales runtime source, firmware/vendor-confidential material and private keys are intentionally outside the public support scope.
